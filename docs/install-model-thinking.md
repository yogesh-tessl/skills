> **Author**：簡光正 Kuang Cheng, Chien
> **Email**：gzjian@gmail.com

---

## 1. 下載 Model Thinking Skill 檔案

> https://books.kcchien.com/skills/model-thinking.skill

點擊上方連結，瀏覽器會自動下載 `model-thinking.skill` 檔案。

---

## 2. 上傳並安裝 Skill 檔案

到 `Claude.ai` 的設定頁面，將上個步驟下載的 `model-thinking.skill` 上傳，安裝完成。

https://claude.ai/customize/skills

操作方式：

1. 進入上方連結，左側選單點選 **Skills**
2. 右上角點選 **＋** 按鈕上傳 `model-thinking.skill`

有看到 **model-thinking** 顯示在 Skills 列表裡即表示安裝完成。

---

## 3. 開始使用

例如直接輸入：

> `幫我用多角度思維模型分析「是否該離職創業」`

Claude 會自動根據提示詞，直接調用 Model Thinking 這個 Skill，從多個心智模型的角度進行分析。

經過一段時間，就會出現包含主要模型分析、互補觀點與綜合建議的完整回覆。

### 更多使用範例

| 提示詞範例 | 說明 |
|-----------|------|
| `用逆向思維分析這個商業計畫的風險` | 指定特定模型（Inversion）進行分析 |
| `幫我想清楚該選哪個 offer` | 引導式模式，Claude 會先問診斷問題 |
| `教我什麼是二階思考` | 教學模式，附帶範例與練習題 |
| `analyze this pricing strategy from multiple angles` | 英文也支援 |
