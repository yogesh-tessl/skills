> **Author**：簡光正 Kuang Cheng, Chien
> **Email**：gzjian@gmail.com

---

## 1. 下載 CRISP Reading Skill 檔案

> https://books.kcchien.com/crisp-reading.skill

點擊上方連結，瀏覽器會自動下載 `crisp-reading.skill` 檔案。

---

## 2. 上傳並安裝 Skill 檔案

到 `Claude.ai` 的設定頁面，將上個步驟下載的 `crisp-reading.skill` 上傳，安裝完成。

https://claude.ai/customize/skills

操作方式：

1. 進入上方連結，左側選單點選 **Skills**
2. 右上角點選 **＋** 按鈕上傳 `crisp-reading.skill`

有看到 **crisp-reading** 顯示在 Skills 列表裡即表示安裝完成。

---

## 3. 開始使用

用自然語言跟 AI 助手對話即可：

| 你說 | 發生什麼事 |
|------|-----------|
| *「幫我讀這本書」* + PDF | 提取全文 → 深度分析 → 互動式 HTML 報告 |
| *「分析《老殘遊記》」*（僅書名） | 自動從 70,000+ 冊公共領域書庫下載全文 → 同樣的深度分析 |
| *「分析《原子習慣》」*（書庫無收錄） | 依 Claude 知識分析，報告中明確標示 |
| *「這本書值不值得讀？」* | 快速 TIPS 四維度評估，不囉嗦 |

Claude 會自動根據提示詞，直接調用 CRISP Reading 這個 Skill，產出一份互動式 HTML 閱讀報告——包含核心論點、批判視角、精選引句與行動計畫。

經過一段時間，就會出現頁面。
