# Device Configuration Tool (DCT)

The Device Configuration Tool is a web-based application for creating and managing device profiles used by Edge Central device services.

## Main Sections

### Introduction
Overview of the tool's purpose and supported protocols.

### Signing In
Account setup and password management procedures.

### Navigation
Searching, filtering, and accessing assistance within the tool.

### Device Types
Operations for managing device types:
- Addition
- Viewing
- Modification
- Duplication
- Removal

### Device Resources
Management of device resources with CSV file importing capabilities, including examples for:
- Modbus protocol
- OPC UA protocol

### Device Profiles
Profile management features:
- Profile creation
- Resource selection
- Import/export functionality
- Command mapping

### Profile Library
Shared profile library capabilities:
- Importing from the Library
- Submitting to the Library

### Troubleshooting
Support contact information and common issue resolution.

### Release Notes
Version changes and updates.

# OPC UA Browser

The OPC UA Browser is a web-based tool for browsing, monitoring, and interacting with OPC UA servers.

## Main Sections

### Introduction
Purpose and overview of the OPC UA Browser.

### Installation
Setup requirements and procedures for deploying the browser.

### User Authentication
Multiple authentication methods including:
- OAuth2 integration
- Standard user credentials

### User Management
Account administration features for managing browser users.

### Connection Settings
Server connectivity configuration for connecting to OPC UA servers.

### Quick Links
Server bookmark functionality for quick access to frequently used servers.

### Certificates
Trust and certificate management for secure OPC UA connections.

### Node Tree
Navigation and search capabilities for browsing the OPC UA address space.

### Attributes and References
Data exploration tools for examining node attributes and references.

### Data View
Subscription and monitoring features for real-time data observation.

### Write Value
Data modification capabilities with multiple value rank support.

### Call Method
Remote method invocation on OPC UA server nodes.

### Audit Logging
Event tracking and logging for audit trail purposes.

### TLS Security
Encryption configuration for secure communications.

### Deployment
Server deployment guidance for production environments.

### Internationalization
Multi-language support for global deployments.
