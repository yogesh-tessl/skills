# Edge Manager Overview

Edge Manager is IOTech's platform for managing distributed edge computing infrastructure. Current version: 3.1.4.

## Core Sections

- **Introduction**: Overview of Edge Manager capabilities
- **Getting Started**: Basic and advanced startup guides
- **Installation**: Server/CLI and node installation instructions
- **Configuration**: Options and management settings
- **Feature Overview**: Comprehensive feature listing

## Feature Areas

Edge Manager provides management capabilities across the following areas:

- **Nodes**: Edge node provisioning and management
- **Apps**: Application deployment and lifecycle management
- **Files**: File distribution to edge nodes
- **Scripts**: Remote script execution
- **Alerts**: Alert configuration and monitoring
- **Automations**: Automated workflows and responses
- **Services**: Service management and monitoring
- **Events**: Event tracking and handling
- **Metrics**: Performance and resource metrics
- **SSH Tunnels**: Secure remote access
- **Port Forwarding**: Network port management
- **Settings**: System configuration
- **Users/Roles**: User management and role-based access control
- **Organizations**: Multi-tenancy organizational structure
