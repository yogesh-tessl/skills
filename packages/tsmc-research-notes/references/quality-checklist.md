## 完成度檢核（必要項目）

> 每篇筆記完成後，逐項確認。全部打勾才算完成。

### 結構完整性

- [ ] 有「一句話結論」，且是**發現**不是**動作**
- [ ] 有「為什麼要做這件事」，且連結到**商業目的**
- [ ] 有至少一個「廠務人員看這裡」區塊
- [ ] 有「對決策的意義」，且每點都有**具體建議**
- [ ] 有「下一步」，且銜接到後續研究問題
- [ ] 有「現場實務未驗證聲明」
- [ ] 有更新日期

### 獨立自足性

- [ ] 所有關鍵對照表、映射表已**完整內嵌**為 Markdown 表格（不是只寫「見 notebook」）
- [ ] 關鍵程式碼片段（特別是不能自動化的步驟）已內嵌並附白話解釋
- [ ] 重要圖表已轉為文字描述或擷取為圖片嵌入
- [ ] 讀者**不需要存取任何外部檔案**就能理解全部內容

### 語言規範

- [ ] 術語首次出現有中文全稱與英文括號
- [ ] 無中英夾雜句子
- [ ] 關鍵數字都附脈絡（代表什麼、好壞標準、對決策意義）
- [ ] 圖表都轉為文字描述（目的、觀察、結論）

### 知識萃取

- [ ] 至少記錄了一個**踩坑經驗**或**失敗嘗試**
- [ ] 至少記錄了一個**反直覺發現**或**隱性知識**（如果有的話）
- [ ] 涉及模型或結論時，有記錄**適用邊界與失效條件**

## 品質壓力測試（經驗傳承有效性）

> 完成度檢核確保「該有的都有」，壓力測試確保「寫得夠好」。以下五項從不同角度檢驗筆記的傳承價值。

### 1. 新人測試（Inversion）

**核心問題**：一個從未接觸過這個專案的工程師，只看這篇筆記，能不能理解分析的邏輯和結論？

檢查項目：
- 是否有足夠的背景脈絡，不需要額外問人？
- 專業術語是否都有解釋？
- 分析步驟之間的邏輯是否清楚？

### 2. 獨立自足測試

**核心問題**：讀者手邊只有這篇 Obsidian 筆記，沒有任何原始分析檔案，能不能完整理解所有內容？

檢查項目：
- 所有被提及的對照表、映射關係是否已**完整內嵌**（不是只說「見 notebook」）？
- 關鍵程式碼片段是否已嵌入並附白話解釋？
- 重要圖表是否已轉為文字描述或擷取為圖片？
- 閾值、篩選條件等「magic number」是否都有記錄來源與設定理由？

### 3. 魔鬼代言人測試

**核心問題**：如果有人挑戰這篇筆記的結論，最強的反駁論點是什麼？筆記中有沒有預先回應？

檢查項目：
- 結論的假設前提是否明確？
- 替代解釋是否有被考慮（例如相關性是否可能由第三變數驅動）？
- 不確定性是否誠實標示？

### 4. 時效性測試

**核心問題**：半年後再看這篇筆記，哪些內容可能已經過時？有沒有標示「保鮮期」？

檢查項目：
- 數據時間範圍是否標明？
- 設備、製程、人員等依賴條件是否記錄？
- 結論是否標示適用的限制條件？

### 5. 「所以呢」測試

**核心問題**：讀完這篇筆記，讀者知不知道**下一步該做什麼**？

檢查項目：
- 每個發現是否都連結到行動建議？
- 「對決策的意義」是否真的可執行（而非空泛的「建議進一步研究」）？
- 「下一步」是否具體到可以直接開始做？

## 常見缺陷模式

> 以下是經驗傳承筆記中最常見的品質問題，寫作時主動避免。

| 缺陷模式 | 症狀 | 修正方式 |
|---------|------|---------|
| **流水帳** | 按分析步驟逐步記錄，沒有提煉重點 | 重組結構：結論先行，再解釋為什麼 |
| **只報喜** | 只記錄成功的分析路徑，沒有踩坑和失敗 | 刻意追問「哪些嘗試失敗了」 |
| **數字堆砌** | 列了大量指標但沒解釋意義 | 每個數字都附「代表什麼、好壞、對決策的意義」 |
| **孤立分析** | 沒有連結到前後的研究問題和整體脈絡 | 在「為什麼」和「下一步」中做銜接 |
| **術語轟炸** | 大量專業術語沒有解釋 | 首次出現補括號術語，複雜概念加「💡小知識」 |
| **過度自信** | 結論寫得很肯定但缺乏限定條件 | 補上「適用邊界與失效條件」表格 |
| **純 AI 視角** | 只從模型角度寫，沒有廠務觀點 | 補上「廠務人員看這裡」和「跨域橋接」區塊 |
| **外部依賴** | 筆記中寫「見 notebook」或「詳見原始分析」，讀者必須去找其他檔案 | 把所有關鍵產物內嵌：對照表、程式碼片段、圖表描述 |

## 附錄更新檢查

> 每篇筆記完成後，檢查是否有新素材應加入附錄。

| 附錄檔案 | 觸發條件 | 要加什麼 |
|---------|---------|---------|
| `附錄-物理約束速查表.md` | 發現了新的物理限制、閾值、或經驗公式 | 參數名稱、約束條件、來源筆記編號 |
| `附錄-踩坑紀錄.md` | 遇到了新的錯誤、陷阱、或反直覺行為 | 症狀、原因、解法、來源筆記編號 |
| `附錄-最佳實務SOP.md` | 確立了新的可重用分析流程或操作建議 | 步驟、適用條件、注意事項、來源筆記編號 |
| `00-目錄與導讀.md` | 新增了任何筆記 | 筆記標題、一句話摘要、連結 |
