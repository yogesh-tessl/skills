# AIPoint Brand Guidelines

Apply these guidelines to maintain consistent AIPoint branding across all materials.

## Brand Identity

**Company**: AIPoint
**Visual Identity**: Stylized dragon logo with cyan-to-green gradient
**Brand Personality**: Innovative, tech-forward, professional, dynamic

## Quick Reference

### Colors

| Purpose | Color | Hex |
|---------|-------|-----|
| Primary Cyan | Gradient start | `#00E5CC` |
| Primary Green | Gradient end | `#3DED97` |
| Accent | Bright green | `#00FF88` |
| Background | Black | `#000000` |
| Text (dark bg) | White | `#FFFFFF` |
| Text (light bg) | Black | `#000000` |

**Gradient CSS**: `linear-gradient(180deg, #3DED97 0%, #00E5CC 100%)`

For detailed color specifications, see [references/colors.md](references/colors.md).

**Primary Font**: Inter (Google Fonts)
**Fallback**: Roboto, Open Sans, system sans-serif

| Element | Size | Weight |

| H2 | 36px | Bold (700) |
| H3 | 24px | Semi-Bold (600) |
| Body | 16px | Regular (400) |

For detailed typography rules, see [references/typography.md](references/typography.md).

## Application Guidelines

### Presentations (PPTX)

1. **Background**: Use black (#000000) or dark (#111111) backgrounds
2. **Title slides**: Apply gradient text effect to main titles
3. **Accent colors**: Use AIPoint cyan/green for highlights, icons, shapes
4. **Logo placement**: Top-right or bottom-right corner, with padding
5. **Charts/graphs**: Use gradient colors for data visualization

### Documents (DOCX)

1. **Headers**: Apply AIPoint green (#3DED97) for section headers
2. **Body text**: Black on white background, Inter or Roboto font
3. **Accent elements**: Use cyan (#00E5CC) for links, callouts
4. **Logo**: Header or title page placement

### Web/Digital

1. **Dark mode preferred**: Black background with gradient accents
2. **Interactive elements**: Cyan for links, green for buttons
3. **Gradient usage**: Apply to hero sections, key CTAs, important headings

## Logo Usage

The AIPoint dragon logo:
- Depicts a stylized dragon forming a circular coil with triangular wing
- Uses vertical gradient: cyan (#00E5CC) at bottom to green (#3DED97) at top
- **Clear space**: Maintain padding equal to the height of the wing
- **Minimum size**: 32px height for digital, 0.5 inches for print
- **Dark backgrounds only**: The gradient logo requires dark backgrounds for visibility

Logo files are located in `assets/logos/` (add logo files to this directory).

## Do's and Don'ts

**Do:**
- Use the full gradient on dark backgrounds
- Maintain consistent typography with Inter font family
- Apply gradient to headings and key visual elements
- Keep designs clean with ample white space

**Don't:**
- Place gradient logo on light backgrounds
- Use colors outside the brand palette
- Stretch or distort the logo
- Mix too many font weights in one design
